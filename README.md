# Dashboard Protagon

Dashboard alinhado ao arquivo `Dashboard-Protagon-Novo-main(1).zip`, com integração
Supabase para leads e tráfego de Joinville, Porto Alegre, Goiânia e São Paulo.
Para ativá-la, configure `SUPABASE_SECRET_KEY` no servidor e publique novamente.
Até a configuração, as praças continuam consultando **GERAL** nas planilhas.

O aplicativo está em **`Dashboard-Protagon-Vercel/`**. Na Vercel, configure
**Root Directory = `Dashboard-Protagon-Vercel`**. A configuração de build e da API
está no `vercel.json` dessa pasta.

Veja [as fontes de dados e instruções de execução](Dashboard-Protagon-Vercel/README.md).
